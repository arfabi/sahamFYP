  1. KEPUTUSAN FINAL
================================================================================

  N8N WORKFLOW:
  
  [1] POST /api/scrape
       → return: { title, content, image, siteName }
  
  [2] POST /api/classify
       → return: { category, ticker, confidence, reason }
  
  [3] POST /api/score
       → return: { score, decision, reason, catalyst, dataQuality }
       → IF decision = "PASS" → STOP
       → IF decision = "GENERATE" → lanjut
  
  [4] POST /api/generate
       → return: { classification, enrichment, naskah, image, siteName }
  
  [5] POST /api/posts
       → simpan ke DB (status: 'generated')
       → return: { post: { id: "xxx" } }
  
  [6] FOR EACH slide in naskah.slides:
       a. Build HTML string dari slide object
       b. POST Browserless.io Screenshot API
          URL: https://chrome.browserless.io/screenshot?token=KEY
          Body: { url: "data:text/html,<slide HTML>", options: {...} }
       → return: PNG binary
  
  [7] Upload PNG → Cloudinary API (direct dari n8n)
       URL: https://api.cloudinary.com/v1_1/{cloud_name}/image/upload
       Body: { file: "<base64 PNG>", upload_preset: "sahamfyp" }
       → return: { secure_url: "https://..." }
  
  [8] POST /api/posts (update)
       → update post dengan cloudinaryUrls
       → status: 'rendered'
  
  [9] POST /api/publish
       → publish ke IG/TikTok via Repliz
       → status: 'scheduled'

================================================================================
  4. BROWSERLESS.IO DETAIL
================================================================================

  Plan          : Free ($0/bulan)
  API Key       : BROWSERLESS_IO_KEY (env variable)

  Limits:
    - 1,000 units/bulan (~8.3 jam browser time)
    - 2 max concurrent browsers
    - 2 min max session time
    - Chrome, WebKit, Firefox

  Unit Calculation:
    - 1 unit = 30 detik browser time
    - Screenshot API: ~1-2 unit per request
    - 8 slides = ~8-16 units per post
    - 1,000 units = ~60-125 posts/bulan (~2-4 posts/hari)

  Screenshot API:
    POST https://chrome.browserless.io/screenshot?token=BROWSERLESS_IO_KEY
    Headers: Content-Type: application/json
    Body: {
      "url": "data:text/html,<html>...</html>",
      "options": { "type": "png", "fullPage": true },
      "viewport": { "width": 1080, "height": 1080 }
    }
    Response: PNG binary
