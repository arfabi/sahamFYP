BASE URL: https://saham-fyp.vercel.app

================================================================================
  DAFTAR API (URUTAN FLOW B2)
================================================================================

[1] POST /api/scrape
     → Scrape berita dari URL
     → API Key: TIDAK PERLU
     
[2] POST /api/classify
     → Classify kategori + ticker
     → API Key: TIDAK PERLU
     
[3] POST /api/score
     → Scoring 0-10 + decision PASS/GENERATE
     → API Key: TIDAK PERLU
     
[4] POST /api/enrich
     → Enrich data Sectors.app
     → API Key: PERLU (header: X-API-Key)
     
[5] POST /api/generate
     → Generate naskah carousel
     → API Key: PERLU (header: X-API-Key)
     
[6] POST /api/posts
     → Save post ke database
     → API Key: PERLU (header: X-API-Key)
     
[7] POST /api/publish
     → Publish ke Repliz
     → API Key: PERLU (header: X-API-Key)
